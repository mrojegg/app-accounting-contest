# Сортировка документов

Локальное приложение для macOS, которое помогает финансовому и административному департаменту обрабатывать банковские чеки, платежные документы и зарплатные ведомости. Оно распределяет документы по офисам и категориям, формирует Excel-таблицы и объединенные PDF, а неоднозначные случаи оставляет для решения пользователя.

Конкурсная версия 1.2.0 запускается без рабочих офисов, сотрудников и контрагентов. Демонстрационные данные вымышленные. Исходная история личного проекта и его конфигурация в этот репозиторий не переносятся.

## Польза для департамента

- Единая структура архива вместо ручного поиска и раскладки сотен чеков.
- Понятные имена документов с получателем, датой и суммой там, где эти поля прочитаны.
- Общая очередь документов, требующих решения, с просмотром оригинала и исправлением реквизитов.
- Сводные зарплатные таблицы по офисам с датами фактических платежей и уникальными получателями.
- Распределение уже оплаченных налогов и взносов по фактическому числу получателей зарплаты.
- Объединенные чеки зарплаты и комиссий в порядке строк таблицы, сохранение отдельных оригиналов.
- Итоговый отчет по входным файлам и ZIP для передачи результата коллегам на Windows.

Приложение не заменяет учетную систему, проверку факта зачисления денег или расчет налоговых обязательств. Снижение затрат времени оценивается на собственном контрольном наборе, а не заявляется без измерения.

## Быстрый запуск

1. Скачайте конкурсный DMG из Releases и перенесите приложение в «Программы».
2. Откройте «Сортировка документов (конкурс)».
3. В разделе «Гайд» → «Офисы» создайте офисы и добавьте юрлица, сотрудников и контрагентов.
4. Для первой проверки выберите «Копировать» и используйте отдельную папку результата.
5. Запустите сортировку, распределите ручную очередь и проверьте «Итог обработки».

Сборка для Apple Silicon; минимальная заявленная версия macOS 13. Нативные компоненты проверены на текущем Mac разработчика, все версии macOS и Intel-сборка отдельно не проверены. Python, PDFKit-обработчик и Vision OCR входят в комплект; устанавливать Python пользователю не требуется.

DMG подписан локальной подписью, а не Developer ID. На другом Mac первая установка может потребовать разрешения в «Системные настройки» → «Конфиденциальность и безопасность». Подпись Apple и нотариализация пока не выполнены.

## Конфиденциальность

Обработка локальная: текущие обработчики не отправляют документы в облачный OCR или языковую модель. Конкурсная сборка использует отдельное хранилище `~/Library/Application Support/SortingFilesContestApp` и отдельный кэш. Она не читает и не заменяет настройки рабочей версии.

Папки результатов содержат исходные документы и реквизиты. Они не шифруются приложением автоматически; доступ, резервное копирование и передачу этих папок контролирует пользователь.

## Текущее состояние

Доступен нативный интерфейс macOS: сортировка, разбивка PDF, объединение PDF, зарплатные Excel и гайд с управлением офисами. Windows в репозитории представлен заготовками для разработки, не готовой конкурсной программой. Мультиязычный интерфейс и облачная синхронизация не заявляются.
